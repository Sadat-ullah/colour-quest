# Colour Quest 🎨

> A joyful, child-friendly HTML5 Canvas colouring and colour-matching game designed for children ages 3–12.

## 🌟 Highlights

* **100 Developmental Levels:** Progressing across 7 tailored age tiers (from basic shapes for toddlers to intricate master scenes for older kids).
* **Warm Storybook Aesthetic:** Clotted cream cards, spruce velvet accents, and juicy 3D tactile buttons inspired by British children's books.
* **Child-Friendly Mechanics:** Zero timers or fail states—tap a shape to select, tap a colour to fill, with single-use hints, undo, and clear options.
* **Procedural Web Audio:** Real-time synthesized bells, pops, liquid whooshes, and celebratory fanfares with zero mobile audio lag.
* **Fully Responsive:** Custom resolution-independent scaling for mobile phones, tablets, laptops, and desktop screens.
* **No Dependencies on Runtime Assets:** Fully self-contained pure TypeScript and HTML5 Canvas 2D.

## 🛠️ Development

```bash
# Clone the repository
git clone https://github.com/Sadat-ullah/colour-quest.git
cd colour-quest

# Install dependencies
npm install

# Start local dev server
npm run dev

# Run unit tests
npm test

# Build production bundle
npm run build
```
